# ほしぞらキャッチ

20秒で果物と星を集めるブラウザーゲームです。ビルドやアプリ実行用の依存パッケージは不要です。

## 開発

`index.html` をブラウザーで開くか、リポジトリのルートで次を実行して HTTP サーバー経由でアクセスしてください。
JavaScript は通常のスクリプトとして依存順に読み込むため、ES Modules の CORS 制限を受けません。
各ファイルは関数スコープに閉じ、共有する機能だけを `window.StarCatch` に公開しています。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

| ファイル          | 役割                                 |
| ----------------- | ------------------------------------ |
| `index.html`      | 画面構造                             |
| `styles.css`      | レイアウト・装飾・モバイル表示       |
| `js/game.js`      | ゲーム状態・時間・出現・衝突・得点   |
| `js/rendering.js` | Canvas 描画・視覚効果                |
| `js/controls.js`  | キーボード・ポインター・自動一時停止 |
| `js/audio.js`     | BGM・効果音・ミュート                |
| `js/rankings.js`  | ランキング表示・保存・JSON 出力      |
| `js/spawning.js`  | アイテム出現・三連星の配置           |
| `js/scoring.js`   | 得点・コンボ・時間延長のルール       |
| `js/dom.js`       | DOM 要素の取得                       |

ランキングの保存キー・JSON 形式は以前のバージョンと同じです。

## 動作確認

Node.js、Playwright、Chromium を用意し、上記サーバーを起動してから実行します。
このクラウド開発環境ではすべて導入済みです。その他の環境では Playwright を Node.js から
読み込めるようにインストールしてください。

```sh
node tests/smoke.cjs
node tests/local-loading.cjs
node tests/features.cjs
node tests/layout-and-triple.cjs
```

`CHROMIUM_PATH` で Chromium の実行ファイル、`TEST_URL` で検証する HTTP URL を指定できます。
テストは独立したブラウザーで EASY/HARD 各20秒のプレイ、一時停止と再開、ランキングの永続化、
JSON 出力、モバイル幅での表示を確認します。音声の実際の聞こえ方は手動で確認してください。

`local-loading.cjs` は不透明なオリジンで開始・一時停止・再開を検証し、モジュールの CORS 制約が出る条件での退行を防ぎます。

## スーパースターとフィーバー

🌟 は出現するアイテムの約1.8%のスーパースターです。キャッチすると＋30点と残り時間＋10秒。通常の ⭐ は＋30点のままです。
5コンボごとに＋20点、3コンボからは果物・星の基本得点が2倍になります（5コンボのボーナスは＋20点のまま）。
爆弾に当たるか、果物・星を取り逃すとコンボとフィーバーがリセットされます。

## 三連星

約5%の確率で、通常の星が同じ横位置・同じ速度で3つ縦に並んで降ります。
1つずつキャッチして各＋30点、3つとも取ると基本得点は合計＋90点です。
既存のコンボボーナスとフィーバーも適用されます。星を取り逃した分の得点は入りません。

## ミニスターとターボ

小さな⭐は約4%で出現する特別アイテムです。取得時に半径240以内の果物・爆弾が通常の星になり、ゲーム内時間で3秒後に元に戻ります。一時停止中は効果時間も止まります。変身中に取ると星の得点になります（時間延長なし）。
籠は通常540、Bキーを押している間は850の速度で移動します（従来620）。
